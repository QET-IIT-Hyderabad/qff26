# Speaker photos

Drop each speaker's photo into this folder to replace the placeholder.

- Use the **exact filename** listed below for each speaker (all lowercase, `.jpg`).
- Recommended size: portrait, around **500 × 625 px** (4:5 ratio), square-ish faces crop fine too.
- Until a real file is present, the site automatically shows `placeholder.svg`.
