# Company / industry logos

Logos used for industry talks in the Speakers section.

- **IBM Quantum** — uses the existing in-repo logo at
  `IBM_Quantum/Raster/RGB/` (theme-aware, no action needed).
- **Quantum AI Global** — drop the logo here as `quantum-ai-global.png`
  (transparent PNG or SVG preferred). Until it exists, the site shows
  `placeholder.svg`.

To add another industry talk, add an entry to the `speakers` array in
`index.html` with either a `logo:` path (single logo) or
`logoDark:`/`logoLight:` paths (theme-swapped logos).
